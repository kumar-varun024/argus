#### Summary & Description

During security analysis of `api.target`, a Sqli vulnerability was identified at endpoint `/search`. The vulnerable input vector is the `q` parameter.

#### Steps to Reproduce

1. Navigate to the target endpoint `/search` on host `api.target`.

#### Impact Analysis

An attacker could manipulate database queries, leading to unauthorized read, modification, or deletion of sensitive database records, or potential administrative takeover.

#### Recommended Remediation

Use parameterized queries or Object-Relational Mapping (ORM) frameworks with prepared statements. Never concatenate untrusted user input directly into SQL queries.
